# Vanshika Jain — Personal Fashion Portfolio

A static, editorial portfolio (HTML / CSS / vanilla JS — no build step).

- `index.html` — structure and content
- `styles.css` — styling (the file ends with a "POLISH PASS" layer that supersedes earlier rules)
- `script.js` — hero slideshow, navigation, collection switcher and lookbook modal, video autoplay
- `assets/` — images, lookbooks (`assets/lookbooks/<collection>/NN.webp`), videos, résumé PDF

Open `index.html` in a browser, or serve the folder (`python3 -m http.server`). Keep the folder structure intact: all assets use relative paths.

## Deploying (GitHub Pages)
Repository **Settings → Pages → Build and deployment → Deploy from a branch → `main` / `/ (root)`**.
